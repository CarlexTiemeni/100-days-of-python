## Day 2 — Tip Calculator

This project calculates how much each person should pay when splitting a bill including a tip.

### How the Program Works

The program asks the user for:

- The total bill amount  
- The tip percentage (10%, 12%, or 15%)  
- The number of people splitting the bill  

The program then:

- Converts the tip percentage into a decimal  
- Calculates the total tip amount  
- Adds the tip to the original bill  
- Splits the total between the selected number of people  

### Example

```
Total bill: $150
Tip: 12%
People splitting the bill: 5

Each person should pay: $33.60
```

### What I Learned

- Converting data types using `int()` and `float()`
- Performing mathematical calculations
- Formatting numbers with `round()`
- Writing Python logic step by step

## Day 5 — Password Generator & FizzBuzz

### Password Generator

This is a Python program that generates a random password based on user input.

#### How the Program Works

The program asks the user:

- How many letters they want  
- How many symbols they want  
- How many numbers they want  

Using this information, the program:

- Randomly selects characters  
- Stores them in a list  
- Shuffles the list  
- Combines them into a final password  

#### Example

```
How many letters would you like in your password?
5
How many symbols would you like?
2
How many numbers would you like?
3

Your password is: aB3$dE9!k
```

#### What I Learned

- Using the `random` module  
- Working with lists (`append`, `shuffle`)  
- Converting lists into strings  
- Building dynamic programs

### FizzBuzz

A classic programming problem that prints numbers from 1 to 100 with conditions.

#### How the Program Works

- Multiples of 3 → "fizz"  
- Multiples of 5 → "buzz"  
- Multiples of both → "fizzbuzz"  
- Otherwise → print the number  

#### Example

```
1
2
fizz
4
buzz
...
15 → fizzbuzz
```

#### What I Learned

- Using `for` loops  
- Applying the modulo operator `%`  
- Writing clean conditional logic
